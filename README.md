## Course Description

Introduces established and evolving methodologies for the analysis, design, and development of an information system. Emphasis is placed on system characteristics, managing projects, prototyping, CASE/OOM tools, and systems development life cycle (SDLC) phases.

## What This Repo Covers

- **Systems Development Life Cycle (SDLC):** Planning → Analysis → Design → Implementation
- **Requirements gathering & documentation analysis** (reading systems like a systems analyst — evidence vs. assumption)
- **Data flow diagrams** and system modeling
- **Version control & collaboration** via Git/GitHub (the course's "Trusted Workflow": Issue → Branch → Draft PR → Dev → Finish PR → Review → Merge)
- **Sprint work:** SQLite integration, RESTful APIs, unit testing
- **Agile/Scrum practices** across two sprint cycles
- **Capstone project:** team-based pitch, planning, and delivery
